# Casa Moraleda · Arturo Soria

Web estática de presentación para Casa Moraleda, en Calle de Agastia, Madrid. Incluye historia, especialidades, carta orientativa, formulario de solicitud de reserva por WhatsApp y mapa.

## Publicación

El flujo de GitHub Actions de `.github/workflows/pages.yml` publica automáticamente el sitio en GitHub Pages al actualizar `main`. En el repositorio, configura **Settings → Pages → Build and deployment → Source → GitHub Actions** si Pages todavía no está habilitado. La URL tendrá el formato `https://adrieq3.github.io/casa-moraleda/`.

Para usar un dominio propio más adelante, añade el dominio en **Settings → Pages → Custom domain**, crea los registros DNS que GitHub indique y activa HTTPS cuando la validación termine.

## Datos y contenidos

- La imagen `cocido.jpg` ya formaba parte del repositorio.
- Las imágenes externas de cachopo y postre son ilustrativas y se sirven desde Unsplash.
- Los precios que no se han podido verificar para la sede de Agastia se muestran como «Consultar». Los importes de cocido y cachopo se mantienen como estaban en el sitio recibido.
- Las solicitudes de reserva abren WhatsApp; no se confirman hasta recibir respuesta del restaurante.
- Verifica horarios, carta, precios e imágenes con el restaurante antes de convertir esta propuesta en su web oficial.
